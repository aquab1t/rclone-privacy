Privacy Policy

rclone Google Drive client · last updated 9 November 2026

This page covers the Google OAuth client named rclone, registered by José Manuel Echevarría Rubio. It is a personal tool, not a public service: its only user is the owner, who uses the open-source program rclone to sync files between his own computers and his own Google Drive.

What data is accessed

With the owner's consent, the client reads and writes files in the owner's own Google Drive account, using the Google Drive API. It does not access any other Google data, and it is not offered to anyone else.

How the data is used and stored

  • Files are copied only between the owner's Google Drive and the owner's own computers.
  • The OAuth tokens that grant access are stored only in the rclone configuration file on those computers.
  • No data is collected, stored on any other server, sold, shared with third parties, or used for advertising or analytics.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
