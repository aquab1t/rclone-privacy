# rclone-privacy

Privacy policy for the personal Google OAuth client "rclone", which the owner
uses to sync files between his own computers and his own Google Drive with
[rclone](https://rclone.org/).

Served by GitHub Pages at <https://aquab1t.github.io/rclone-privacy/>. Google
requires this URL, together with the home page <https://aquab1t.github.io/>,
before the OAuth app can be published (which ends the 7-day login expiry of
Testing mode).

## Files

- `index.html`: the privacy policy (HTML and CSS inline, no scripts). Edit directly.
- `.nojekyll`: tells GitHub Pages to serve the files as they are.
